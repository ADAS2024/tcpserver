This is a project designed to explore how to use the tcp/ip protocol.
To run the project, run the server.c file in serverfiles and then you can run multiple clients through client.c. You might need to change the server address.
You'll be presented with an interface. In it, you can choose to either do file transfer or enter a chatroom to speak with other clients.
If you're in the chatroom, you can talk normally or send encoded messages. Other people in the chatroom can decode those messages.
